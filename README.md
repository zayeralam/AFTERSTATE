# AFTERSTATE\n\nLocal-first commitment accountability dashboard. Track commitment status and risk heuristics.\n\n## Run\nNode.js 18+ required. Run `npm start`, then open http://localhost:3000.\n\n## Test\nRun `npm test`.\n\n## Features\nCRUD, search/filter, owner/due date/priority/status, heuristic risk score, recovery queue, activity log, JSON export.\n\n## Safety boundary\nSingle-user local prototype, without authentication or TLS. Do not expose publicly. Local data is stored in data.json. Risk scores are heuristics, not predictions.\n\n## CI\nGitHub Actions runs the test suite on pushes and pull requests to main.\n
